# HiddenTrunc

R package for hidden-truncation probability models and statistical inference.

This is a development repository being prepared for CRAN. The package has not yet been verified by R CMD check in this workflow.

## Install from source

From the parent directory, run `R CMD INSTALL HiddenTrunc`.

## Bugs

Please report reproducible issues at https://github.com/ginni88/HiddenTrunc/issues.
