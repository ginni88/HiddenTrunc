# HiddenTrunc 0.2.0

* Added the Floyd River flood-discharge benchmark data used by Ghosh and Balakrishnan (2017).
* Added `gof_htp4()` for Kolmogorov--Smirnov diagnostics with optional parametric-bootstrap calibration.
* Added `boot_ci_htp4()` for parametric-bootstrap confidence intervals.
* Added a complete JSS-oriented replication script under `inst/replication/code.R`.
* Expanded tests and reproducibility infrastructure.
